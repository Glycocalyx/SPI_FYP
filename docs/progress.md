# SPI FYP Development Progress

## Project Goal

Design a synthesizable SPI Master Controller for a digital ASIC flow using:

- SystemVerilog RTL
- Cadence Xcelium
- Cadence Genus
- Cadence Innovus
- TSMC 180 nm BCD process

The SPI Master will communicate with multiple external SPI Slave devices.

---

## Current SPI Specification

Current first-version specification:

- SPI Master Controller
- One Master
- Two external Slaves
- Shared SCLK
- Shared MOSI
- Shared MISO
- Independent active-low chip selects
- CSB0 for Slave 0
- CSB1 for Slave 1
- SPI Mode 0
- CPOL = 0
- CPHA = 0
- 8-bit transaction
- MSB first
- Full duplex
- One 8-bit word per transaction
- No FIFO
- No APB/AHB/AXI interface in the first version
- No CRC
- No DMA

Clock frequency and final SCLK frequency are not fixed yet.

CLK_DIV is therefore parameterized in the RTL.

---

## Clock Architecture

The design currently uses one internal system clock:

clk / system_clk

The SPI Master operates entirely in the system clock domain.

SCLK is generated by the SPI Master from the system clock using a programmable clock divider.

Relationship:

system_clk
    |
    v
SPI Master
    |
    v
SCLK
    |
    v
External SPI Slaves

SCLK is an SPI interface output and is not currently used as the internal clock of the SPI Master logic.

---

## SPI Mode 0 Timing

Mode 0:

- CPOL = 0
- CPHA = 0
- SCLK idle level = 0
- Data is sampled on the rising edge of SCLK
- Data changes on the falling edge of SCLK

For MSB-first transmission:

bit7 -> bit6 -> bit5 -> ... -> bit0

The first MOSI bit must be valid before the first rising edge of SCLK.

---

## Current SPI Master Architecture

The current SPI Master contains:

- FSM
- Clock divider
- TX shift register
- RX shift register
- Bit counter
- Slave-select / chip-select control

FSM states:

IDLE
-> LOAD
-> TRANSFER
-> FINISH
-> IDLE

### IDLE

- SCLK = 0
- CSB0 = 1
- CSB1 = 1
- busy = 0
- wait for start

### LOAD

- latch tx_data
- clear RX shift register
- initialize bit counter to 7
- select Slave 0 or Slave 1
- prepare MOSI bit7

### TRANSFER

For each SPI bit:

- SCLK rising edge:
  - sample MISO

- SCLK falling edge:
  - shift TX register
  - update MOSI
  - decrement bit counter

After bit0 completes, move to FINISH.

### FINISH

- return SCLK to 0
- release all CSB signals
- copy RX shift register to rx_data
- busy = 0
- generate one-cycle done pulse
- return to IDLE

## Current RTL Files

### rtl/spi_master.sv

Main synthesizable SPI Master Controller.

Current external interface:

- clk
- rst_n
- start
- slave_sel
- tx_data[7:0]
- busy
- done
- rx_data[7:0]
- sclk
- mosi
- miso
- csb_n[1:0]

### tb/spi_slave_model.sv

Simple SPI Slave behavioral model used only for verification.

It is not currently part of the intended synthesized ASIC RTL.

Slave 0 can be configured to return a known response byte.

### tb/spi_master_tb.sv

First self-checking testbench.

Initial test:

Master sends:

0xA5

Slave 0 returns:

0x3C

Expected results:

Master RX = 0x3C

Slave RX = 0xA5

Both directions must pass to verify full-duplex operation.
